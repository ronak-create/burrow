Workspace & files

A workspace is a folder, owned entirely by whoever made it, with nothing hidden in an app-support directory.

Folder layout

<Documents>/Burrow/<id>/ workspace.json metadata board.json { nodes, edges, ink, viewport } transcript.jsonl append-only, text only, never audio documents/ images/

board.json

Board state is exactly { nodes, edges } in shape, the same object React Flow renders and the assistant's tools read and write. Ink strokes and the current viewport ride along in the same file, so a workspace folder is a complete, portable copy of a board.

transcript.jsonl

Conversation history is appended as plain text, one JSON object per line, and never holds audio: recordings are transcribed and discarded, not archived.

Pinning & search

Workspaces can be pinned in the workspace browser, and a single search reaches across every board and every transcript at once, rather than one workspace at a time.
