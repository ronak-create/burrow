Docs / The canvas

The canvas

One infinite board, built on React Flow, where board state and the assistant's view of the board are the same object.

Blocks

Note, text, shape, frame, table, diagram, doc, and image blocks all live on the canvas, drawn wherever a hand or a tool call puts them rather than dropped at the viewport center. Freehand ink and an eraser sit alongside them, and one undo stack covers all of it: Ctrl+Z undoes whichever edit happened last, no matter who made it.

One command layer

The load-bearing idea sits in src/canvas/commands.ts: every mutation of the board, from the UI and from the assistant alike, goes through a single apply(board, command). That is what makes the shared undo stack possible, and it means the assistant's tool schemas are generated from the same command union the UI uses, so the two cannot drift apart.

Fifteen tools

The assistant writes blocks, connects them, frames them, and flags what it is unsure about, using the same commands a person clicking around the canvas would trigger. It also reads documents, reads handwriting on the ink layer, and can search papers or the open web when asked, covered in Documents & search.
