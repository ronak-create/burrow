Documents & search

What a workspace can read, and where it can look things up.

Importing documents

PDF, Word, Markdown, and plain text files import into a workspace, get read in-app, and can be excerpted onto the board next to whatever they support. Imported files are copied into the workspace's own documents/ folder, covered in Workspace & files.

Paper search

The assistant can search across several open literature indexes on request, pulling results straight onto the board rather than into a separate results pane.

Web search & images

Web search and image generation are both bring-your-own-key and both provider-agnostic, including a custom OpenAI-compatible endpoint, so a local image server works the same way a local model does. Generated images are saved as files in the workspace's images/ folder, not as inline data.
