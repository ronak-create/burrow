Docs / Architecture

Architecture

Three layers: a native shell, a canvas library, and a frontend on top of both.

Shell

Tauri v2, Rust plus WebView2 on Windows or WKWebView on macOS, chosen over a plain browser app for real filesystem access, OS-keychain key storage, background wake-word listening, and an HTTP client that is not CORS-bound, which removes any need for a relay proxy in front of local servers.

Canvas

React Flow (@xyflow/react, MIT). Every block is a plain React component, and board state is literally { nodes, edges } JSON, which doubles as the file format on disk and as the assistant's structured view of the board.

Frontend

React 19, Vite, and TypeScript.
