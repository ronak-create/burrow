Burrow

A voice-driven research assistant that keeps a canvas of notes, documents, and diagrams on the machine it runs on, and nowhere else unless asked.

Download for Windows v0.2.0 · 5.5 MB · MIT

First chamber

One canvas, fully wired.

Six things it does out of the box, running on one infinite board.

The assistant

Fifteen tools let it write blocks, connect them, frame them, and flag what it is unsure about. It reads documents, reads handwriting, and searches papers and the open web on request.

The board

Notes, tables, diagrams, and images drawn where a hand puts them, not dropped at the center. Ink and undo are shared with the assistant.

The wake word

Saying "Hey Burrow" opens a microphone that stayed closed until asked.

What gets read

PDF, Word, Markdown, and plain text import, get read in-app, and get excerpted onto the board.

Any endpoint that speaks the API

OpenAI, Groq, Cerebras, or a custom URL, for language and for speech.

Nothing leaves uninvited

Boards, documents, and transcripts sit as plain files on disk. Keys live in the OS keychain, or don't exist.

Second chamber

Runs closed unless it's told to open.

No account, no telemetry, and no call leaving the machine when the model in Settings is a local one. Ollama or any OpenAI-compatible server works the same way a hosted provider would.
